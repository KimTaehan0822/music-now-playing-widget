Music Now Playing Widget Manual

2026-11-11 · v0.3.0

A widget program that shows the title, artist, album art and play time of the song you are listening to on your stream (OBS). It works with any player: Spotify, YouTube Music, Melon, Apple Music, TIDAL and more, because it reads the "now playing" information Windows already has (the same information that pops up when you press a volume key).

Made by 김탄2 (Kimtan2)

You need these four things.

DownloadMusicNowPlayingWidget-v0.3.0.zip

There is nothing to install. You only run one exe from the unzipped folder.

Step 1: Start the program

  1. Unzip MusicNowPlayingWidget-v0.3.0.zip into any folder.

  2. Double-click MusicNowPlayingWidget.exe.

  3. If a blue "Windows protected your PC" window appears, click More info → Run anyway. This warning appears because it is a free program made by an individual, without a paid Microsoft certificate.

  4. On the first run, the settings page opens in your browser. When a green music note icon appears at the bottom right of the taskbar, the program is running.

The program has no window; it runs as a tray icon only. Starting it twice still runs only one copy.

Step 2: Add the widget to OBS

  1. On the settings page, under URLs for OBS, click Copy next to the style you want. You can also use the tray icon → Copy widget URL.

  2. In OBS, choose Add Source (+) → Browser and name it.

  3. Paste the copied address into the URL field. It looks like file:///C:/Users/.../MusicNowPlayingWidget/widget/widget.html?style=A (a widget file saved on your PC).

  4. Set Width and Height as in the table below and click OK. The settings page also shows the size under each name.

StyleURL endingWidth × HeightLooks like
Card?style=A430 × 110A card with album art, title, artist and progress bar. The album colors glow softly behind it.
Pill?style=B450 × 70A single rounded line with small album art and moving equalizer bars.
Big text?style=C560 × 140No background box, just large album art and large text.

Put a different address in each scene to use a different style per scene. The widget background is transparent.

You can start OBS and this program in either order. The widget waits for the program and connects by itself.

Step 3: Play a song to check

  1. Play a song in your music player. The title, artist and album art appear in the widget.

  2. When you pause, the widget disappears after 1.5 seconds. It comes back when you play again.

  3. When you skip, the old song fades out and the new one fades in. If you skip quickly in a row (again within 0.8 seconds), it switches right away without waiting.

If the widget doesn't appear, see Troubleshooting at the end.

Settings page

Use the tray icon → Open settings, or open http://localhost:8976/settings in a browser. Click Save after a change and the OBS widget updates right away; you don't need to refresh OBS. The preview on the right shows the result before you save.

Why browsers start turned off

Browsers such as Chrome, Edge and Whale also report YouTube videos and live streams as "playing". So browsers start turned off, to keep video titles off your stream.

Windows only reports which browser is playing, not which site. So if you turn Chrome on, everything you play in Chrome shows up, including live streams and videos, not just YouTube Music. To show only YouTube Music, follow the next section.

Show only YouTube Music (without video or stream sound)

If you install YouTube Music as a Chrome app, Windows reports it separately from regular Chrome. Then you can turn on YouTube Music and leave Chrome off.

  1. Open music.youtube.com in Chrome.

  2. Click the install icon at the right end of the address bar (a monitor with a down arrow), then Install. If you don't see it, open the three-dot menu at the top right → Cast, save, and share → Install page as app.

  3. Play a song in the new YouTube Music window. From now on, open it from the YouTube Music icon on your desktop or Start menu.

  4. When YouTube Music (Chrome app) appears under Apps to show on the settings page, turn it on, leave Chrome off, and click Save.

Songs you play in the YouTube Music window then show up, even ones without album info such as covers, while streams and videos in regular Chrome tabs don't.

Add a program that isn't listed

Click Add a running program under Apps to show to see the programs that have a window open. Pick the one that plays your music, choose how to read it, and click Save.

How to readWhat it does
Windows media infoDecide on or off before the program plays anything. Once it plays a song, the row joins the list above.
Window titleFor programs that don't report to Windows. The song is read from the window title, as Title - Artist or Artist - Title.

With window titles, album art and play time don't show, and only programs that put the song in their window title can be read. The song shows while the program makes sound and hides about 3 seconds after the sound stops. A song Windows reports is shown first.

Tray menu

Right-click the green music note icon at the bottom right of the taskbar to open this menu. Double-click the icon to open the settings page directly.

MenuWhat it does
Open settingsOpens the settings page in your browser.
Copy widget URLCopies the widget address for OBS (default style).
RestartCloses the program and starts it again. The OBS widget reconnects by itself.
QuitCloses the program. The widget has no song to show and stays hidden.

When you run a new version, the OBS widget also reloads itself once and switches to the new version.

Troubleshooting

SymptomCauseFix
The widget doesn't appearThe song is paused, or that player is turned offCheck that the song is really playing, and that the player is on under Settings → Apps to show
Chrome stream or video titles appearChrome is on under Apps to showTurn Chrome off and save. Install YouTube Music as a Chrome app as described above
"Port 8976 is already used by another program" appearsAnother program uses the same numberOpen %APPDATA%\MusicNowPlayingWidget\settings.json in Notepad, change the number in "port": 8976 (for example to 8977) and start the program again. The address in OBS can stay as it is
The settings page doesn't openThe address uses 127.0.0.1Open it with localhost. Without admin rights, Windows only allows localhost
No album artThe player sends no picture, or Show album art is offCheck that Show album art is on. The picture can arrive a few seconds after a song change
Something behaves oddly-Tray icon → Restart. If that doesn't help, click "Refresh cache of current page" in the OBS Browser source properties
