# OBS 지금 재생 중 위젯 — 설계

날짜: 2026-11-09

## 무엇을, 왜

방송 화면(OBS)에 지금 재생 중인 곡의 제목·가수·앨범 사진을 보여주는 위젯.
처음 사용자는 스포티파이를 쓰는 방송인 본인이지만, 깃허브에 **무료로 공개**해서
유튜브 뮤직·멜론·애플 뮤직·타이달을 쓰는 다른 방송인들도 쓰게 하는 것이 목표다.
받는 사람 대부분은 개발자가 아니다.

## 목표

- 프로그램(exe) 하나를 실행하고, OBS 브라우저 소스에 `http://localhost:<포트>/widget`을 넣으면
  지금 재생 중인 곡이 보이고, 곡이 바뀌면 곧바로 바뀐다.
- Windows 미디어 세션(GSMTC, `GlobalSystemMediaTransportControlsSessionManager`)에 정보를 올리는 앱이면
  플레이어 종류와 상관없이 동작한다.
- 위젯 모양 3가지를 모두 제공하고, 설정 페이지에서 고른다.
  - A. 카드형: 앨범 사진, 제목/가수, 재생 진행 막대. 뒤에 앨범 색이 흐리게 번진다(Amuse 느낌).
  - B. 한 줄 알약형: 작은 원형 앨범 사진, 재생 중 표시, 제목 + 가수가 한 줄로 나온다.
  - C. 배경 없는 큰 글씨형: 큰 앨범 사진과 그림자 있는 글씨만 나온다.
  - 시안: `.superpowers/brainstorm/*/content/widget-style.html`
- 설정 페이지 `http://localhost:<포트>/settings`
  - 모양 선택(A/B/C), 색 3가지(글자색, 배경색, 포인트색)
  - 앨범 사진 켜기/끄기, 진행 막대 켜기/끄기
  - **표시할 앱 선택**: 지금까지 감지된 앱 목록(예: Spotify.exe, chrome.exe)을 체크박스로 보여준다.
    체크 해제한 앱의 재생 정보는 무시한다. (사용자가 "꼭 넣어야 한다"고 정함)
    처음 감지된 앱은 기본으로 **체크됨**. 단, 알려진 브라우저(chrome, msedge, whale, firefox, opera, brave 등)는
    기본으로 **체크 해제**한다. 유튜브 뮤직을 브라우저로 쓰는 사람은 한 번 켜야 하고, README에 이 내용을 적는다. (사용자 결정)
  - 모양은 위젯 주소마다 다르게 줄 수 있다: `/widget?style=A|B|C`. 장면마다 다른 주소를 넣으면 된다.
    style을 빼면 설정 페이지에서 고른 기본 모양을 쓴다. 색·표시 항목·앱 선택은 모든 위젯이 공통으로 쓴다.
    설정 페이지는 모양별 주소를 복사하는 버튼을 준다. (사용자 결정)
  - 미리보기가 즉시 바뀌고, 저장하면 OBS에 떠 있는 위젯에도 새로고침 없이 반영된다.
- 일시정지하거나 아무것도 재생하지 않으면 위젯이 부드럽게 사라지고, 재생하면 다시 나타난다.
- 배포 파일은 zip 하나(exe + README + LICENSE + 글꼴 라이선스)다. 받는 사람은 .NET 등 아무것도 설치하지 않는다.
  **이번 작업은 이 PC에서 zip을 만드는 데까지만 한다.** 깃허브 저장소 생성과 릴리스 공개는 나중에 사용자 확인을 받고 따로 한다.
  라이선스는 MIT로 하고, 포함하는 Pretendard 글꼴의 OFL 라이선스 파일을 같이 넣는다. (사용자 결정)
  저장소는 로컬 git으로만 관리한다.
- **언어: 한국어·영어·일본어** (사용자 결정). 설정 페이지와 트레이 메뉴, 오류 알림이 대상이다.
  처음에는 Windows 표시 언어를 따른다. ko→한국어, ja→일본어, 그 밖에는 영어다.
  설정 페이지에서 언어를 바꿀 수 있다. 문구는 언어별 사전 파일 하나에 모아 두어서 나중에 언어를 추가하기 쉽게 한다.
  README도 세 언어로 쓴다(README.md는 영어, README.ko.md, README.ja.md).
- README: 실행 방법, OBS 브라우저 소스 추가 방법, SmartScreen 경고("추가 정보 → 실행") 안내,
  플레이어별 "확인됨 / 확인 안 됨" 표.

## 하지 않는 것 (비목표)

- 맥/리눅스 지원. GSMTC는 Windows 10/11 전용이다.
- 플레이어별 API(스포티파이 API 로그인 등) 연동. 오직 GSMTC만 쓴다.
- 재생 조작(다음 곡, 일시정지 버튼).
- 판매, 라이선스 키, 자동 업데이트, Windows 시작 시 자동 실행.
- 한국어·영어·일본어 이외의 언어.
- 같은 크롬 안에서 유튜브 뮤직 탭과 일반 유튜브 영상 탭을 구분하는 것.
  GSMTC는 앱(chrome.exe) 단위로만 구분된다. README에 적는다.

## 실패로 보는 것 (안티 목표)

- 백신이 바이러스로 잡거나, 설치할 게 많아서 초보 방송인이 못 쓰는 것.
- 곡이 바뀌었는데 몇 초씩 늦게 바뀌는 것.
- 방송 중 엉뚱한 소리(브라우저 영상 등)의 제목이 화면에 뜨는 것.
- 멈춘 곡이 화면에 계속 남아 있는 것.

## 제약

- Windows 10(1809 이상)/11.
- OBS 브라우저 소스(CEF/크로미움)에서 투명 배경으로 렌더링되어야 한다.
- 이 PC에는 .NET 런타임만 있고 SDK는 없다. 개발 중에 .NET SDK를 설치한다.
- 이 저장소는 `companion-module-rme-totalmix`와 별개다: `obs-now-playing`.

## 만드는 방식 (검토한 방법)

| 방법 | 장점 | 단점 |
|---|---|---|
| **1. C#/.NET exe (선택)** | GSMTC 공식 API, 곡 변경 이벤트를 즉시 받음, 앨범 사진을 쉽게 읽음, 트레이 아이콘이 쉬움 | 개발 PC에 SDK 필요, exe 약 30~70MB |
| 2. 파이썬 + PyInstaller | 파이썬이 이미 설치됨 | PyInstaller exe는 백신 오탐이 잦음: 배포에 치명적 |
| 3. Node.js + 파워셸 폴링 | 지금 바로 동작 확인됨 | 변경을 몇 초 늦게 앎, 무겁고 불안정 |

사용자가 1번을 골랐다. 이유: 남에게 나눠 줄 프로그램이라 안정성과 백신 문제가 가장 중요하다.

## 정해진 구조

- **exe 하나**(self-contained, single-file 게시). 실행하면 작업 표시줄 트레이 아이콘이 생기고
  메뉴는 "설정 열기", "위젯 주소 복사", "종료" 세 가지다. 콘솔 창은 띄우지 않는다.
- exe 안에 작은 로컬 웹 서버가 있다. `localhost`에서만 받는다.
  - `/widget`: OBS용 위젯 페이지(투명 배경)
  - `/settings`: 설정 페이지
  - `/events`: 위젯과 설정 페이지에 곡 정보와 설정 변경을 실시간으로 밀어 주는 통로
  - `/art`: 현재 앨범 사진
  - 설정 읽기/저장, 감지된 앱 목록을 주는 API
- HTML/CSS/JS는 exe 안에 포함한다(파일을 따로 들고 다니지 않음).
- 설정은 `%APPDATA%\ObsNowPlaying\settings.json`에 저장한다.

### 어떤 세션을 보여줄지
1. 체크 해제된 앱의 세션은 버린다.
2. 남은 것 중 "재생 중"인 세션을 고른다. 여럿이면 Windows가 "현재 세션"으로 꼽는 것을 우선하고,
   그 세션이 해당되지 않으면 가장 최근에 재생을 시작한 것을 고른다.
3. 재생 중인 것이 없으면 위젯을 숨긴다.

## 빌더에게 맡기는 것 (내가 정한 기본값, 바꿔도 됨)

- 기본 포트: 충돌이 적은 번호 하나를 고정한다. 이미 쓰는 중이면 트레이 알림으로 알린다.
  포트 변경은 settings.json에서만 한다.
- 웹 서버 구현(HttpListener 또는 Kestrel), 실시간 통로 방식(SSE 권장: 끊기면 브라우저가 자동으로 다시 연결함).
- 진행 막대: GSMTC가 주는 재생 위치를 받아 브라우저에서 1초 단위로 보간한다.
  위치 정보를 안 주는 앱에서는 막대를 숨긴다.
- 곡이 바뀌는 순간 잠깐 멈춤 상태가 끼는 것을 감안해, 숨기기 전에 1~2초 기다린다.
- 긴 제목: 넘치면 천천히 옆으로 흐르게 한다.
- 글꼴: Pretendard를 포함하고, 일본어·중국어는 Windows 기본 글꼴(Yu Gothic UI, Microsoft YaHei)로 보완한다.
- 기본 색과 처음 실행 시 기본 모양(A 카드형).
- 위젯 크기: OBS에서 브라우저 소스 크기로 맞춘다. 크기 설정 항목은 따로 두지 않는다.

## 확인 기준

- 이 PC에서 OBS 브라우저 소스에 위젯 URL을 넣고 스포티파이로 재생하면 곡이 보인다.
  곡을 넘기면 바로 바뀌고, 일시정지하면 사라진다.
- 설정 페이지에서 모양과 색을 바꾸고 저장하면 OBS 위젯에 바로 반영된다.
- 크롬은 처음부터 체크 해제되어 있어서 크롬 영상 소리가 위젯에 뜨지 않는다. 체크하면 뜬다.
- `/widget?style=B`와 `/widget?style=C`가 각각 다른 모양으로 동시에 나온다.
- 다른 플레이어(유튜브 뮤직/멜론/애플 뮤직/타이달)는 이 PC에서 가능한 것만 확인하고,
  나머지는 README에 "확인 안 됨"으로 표시한다.
