Music Now Playing Widget 取扱説明書

2026-11-10 · v0.2.0

配信画面(OBS)に、いま聴いている曲のタイトル、アーティスト、アルバムアート、再生時間を表示するウィジェットプログラムです。Spotify、YouTube Music、Melon、Apple Music、TIDAL など、どのプレイヤーで聴いても使えます。Windows が持っている「再生中」の情報(音量キーを押したときに表示される情報)をそのまま読み取るためです。

作者: ドクターゴブリン(닥터고블린)の Kimtan2(김탄2)

必要なもの

次の 4 つが必要です。

項目必要なもの
パソコンWindows 10(1809 以降)または Windows 11
OBSブラウザソースが使える OBS Studio(OBS Studio 32 で確認)
音楽プレイヤーWindows の「再生中」に曲を知らせるプレイヤー(Spotify のデスクトップアプリなど)
ダウンロードファイルMusicNowPlayingWidget-v0.2.0.zip

別途インストールするものはありません。展開したフォルダーの exe を 1 つ実行するだけです。

ステップ 1: プログラムを起動する

  1. MusicNowPlayingWidget-v0.2.0.zip を好きなフォルダーに展開します。

  2. MusicNowPlayingWidget.exe をダブルクリックします。

  3. 青い「Windows によって PC が保護されました」画面が出たら、詳細情報 → 実行を押します。個人が作った無料ソフトで、Microsoft の有料証明書がないために表示される警告です。

  4. 初回起動時はブラウザで設定ページが開きます。タスクバー右下に緑の音符アイコンが出れば起動しています。

プログラムにはウィンドウがなく、トレイアイコンだけで動きます。2 回起動しても 1 つだけ動きます。

ステップ 2: OBS にウィジェットを入れる

  1. 設定ページの OBSに入れるURL で、使いたいデザインの横のコピーを押します。トレイアイコン → ウィジェットのURLをコピーでも構いません。

  2. OBS でソースを追加(+) → ブラウザを選び、名前を付けます。

  3. URL 欄にコピーしたアドレスを貼り付けます。アドレスは file:///C:/Users/.../MusicNowPlayingWidget/widget/widget.html?style=A のような形です(PC に保存されたウィジェットファイルです)。

  4. 幅と高さを下の表のとおりに合わせて OK を押します。設定ページでも各名前の下にサイズが書かれています。

デザインURLの末尾幅 × 高さ見た目
カード?style=A430 × 110アルバムアート、タイトル、アーティスト、再生バーのあるカード。後ろにアルバムの色がやわらかくにじみます。
ピル(1行)?style=B450 × 70丸いピル型の 1 行。小さなアルバムアートと動くイコライザーがあります。
大きな文字?style=C560 × 140背景の箱がなく、大きなアルバムアートと大きな文字だけが表示されます。

シーンごとに違うアドレスを入れれば、シーンごとに違うデザインを使えます。ウィジェットの背景は透明です。

OBS とこのプログラムはどちらを先に起動しても大丈夫です。ウィジェットがプログラムを待って自動で接続します。

ステップ 3: 曲を再生して確認する

  1. 音楽プレイヤーで曲を再生します。ウィジェットにタイトル、アーティスト、アルバムアートが表示されます。

  2. 一時停止すると 1.5 秒後にウィジェットが消え、再生すると再び表示されます。

  3. 曲を送ると、前の曲が消えてから新しい曲が表示されます。続けて素早く送ると(2 秒以内にもう一度送ると)、待たずにすぐ切り替わります。

ウィジェットが表示されないときは、最後のトラブルシューティングを確認してください。

設定ページ

トレイアイコン → 設定を開くを押すか、ブラウザで http://localhost:8976/settings を開きます。変更して保存を押すと OBS のウィジェットにすぐ反映され、OBS を更新する必要はありません。右側のプレビューで保存前の見た目を確認できます。

項目説明
デザインURL に ?style= を付けていないウィジェットの標準デザイン
色文字色、背景色、アクセント色(再生バー、イコライザー)
曲ごとに自動で色を変える(アルバムアートの色)オンにすると、曲が変わるたびにウィジェットの色がアルバムアートの色へ約 3 秒かけてなめらかに変わります。文字色は背景に合わせて常に読みやすい色(白または黒)になります。アルバムアートがない曲は上で選んだ色を使い、大きな文字デザインはアクセント色だけが変わります。
アルバムアート / 再生バー / 再生時間それぞれ表示・非表示。再生時間は 1:12 / 3:20 のように表示されます。
表示するアプリ一度でも再生したアプリが一覧に出ます。チェックを外すと、そのアプリの曲はウィジェットに出ません。
Windows の起動時に自動で実行オンにすると、Windows にサインインしたときにプログラムが自動で起動します。最初はオフです。プログラムのフォルダーを移動すると自動で起動しなくなることがあるので、移動したら新しい場所から一度手動で起動してください。
言語自動(Windows の言語) / 한국어 / English / 日本語。設定ページとトレイメニューの文字が変わります。

ブラウザが最初オフになっている理由

Chrome、Edge、Whale などのブラウザは、YouTube の動画やネット配信の音も「再生中」として扱われます。配信中に動画のタイトルが出ないよう、ブラウザは最初オフになっています。

Windows は「どのブラウザで再生中か」だけを伝え、どのサイトかは伝えません。そのため Chrome をオンにすると、YouTube Music だけでなく Chrome で流す配信や動画もすべてウィジェットに出ます。YouTube Music だけを表示するには、次の項目のとおりに設定してください。

YouTube Music だけを表示する(動画・配信の音は除く)

YouTube Music を Chrome アプリとしてインストールすると、Windows は通常の Chrome とは別に伝えます。これで YouTube Music だけをオンにし、Chrome はオフにしておけます。

  1. Chrome で music.youtube.com を開きます。

  2. アドレスバー右端のインストールアイコン(モニターに下向き矢印)を押し、インストールを押します。見当たらない場合は、右上の縦に点が 3 つ並んだメニュー → キャスト、保存、共有 → ページをアプリとしてインストールを押します。

  3. 新しく開いた YouTube Music のウィンドウで曲を再生します。次回からはデスクトップやスタートメニューの YouTube Music アイコンから開いてください。

  4. 設定ページの表示するアプリに YouTube Music (Chrome アプリ) が出たらオンにし、Chrome はオフのまま保存します。

これで YouTube Music のウィンドウで流す曲は、カバー曲のようにアルバム情報がない曲も表示され、通常の Chrome タブの配信や動画は表示されません。

トレイメニュー

タスクバー右下の緑の音符アイコンを右クリックすると出るメニューです。アイコンをダブルクリックすると、設定ページがすぐに開きます。

メニュー動作
設定を開くブラウザで設定ページを開きます。
ウィジェットのURLをコピーOBS に入れるウィジェットのアドレス(標準デザイン)をコピーします。
再起動プログラムを終了して再び起動します。OBS のウィジェットは自動で再接続します。
終了プログラムを終了します。ウィジェットは曲の情報がなくなり表示されなくなります。

新しいバージョンに替えて起動すると、OBS のウィジェットも自動で 1 回再読み込みして新しいバージョンになります。

プレイヤー別の確認状況

プレイヤー状況
Spotify(デスクトップアプリ)確認済み
YouTube Music(Chrome アプリとしてインストール)確認済み
Melon(デスクトップアプリ)未確認
Apple Music(Windows アプリ)未確認
TIDAL(デスクトップアプリ)未確認

音量キーを押したときに Windows に曲の情報が表示されるプレイヤーなら、ほぼ確実に動作します。

トラブルシューティング

症状原因対処
ウィジェットが表示されない曲が一時停止中、またはそのプレイヤーがオフ曲が実際に再生中か、設定 → 表示するアプリでそのプレイヤーがオンかを確認
Chrome の配信や動画のタイトルが出る表示するアプリで Chrome がオンChrome のチェックを外して保存。YouTube Music は前述の方法で Chrome アプリとしてインストール
「ポート8976は他のプログラムが使用中のため起動できません」と出る他のプログラムが同じ番号を使用%APPDATA%\MusicNowPlayingWidget\settings.json をメモ帳で開き、"port": 8976 の数字を変えて(例: 8977)プログラムを再起動。OBS に入れたアドレスはそのままで構いません
設定ページが開かないアドレスに 127.0.0.1 を使っているlocalhost で開く。Windows は管理者権限なしでは localhost だけを許可します
アルバムアートが出ないプレイヤーが画像を送っていない、またはアルバムアート表示がオフ設定でアルバムアート表示がオンか確認。画像は曲が変わってから数秒遅れて届くこともあります
何かおかしい-トレイアイコン → 再起動。それでも直らなければ、OBS のブラウザソースのプロパティで「現在のページのキャッシュを更新」
