Music Now Playing Widget 사용설명서

2026-11-10 · v0.2.1

방송 화면(OBS)에 지금 듣고 있는 곡의 제목, 가수, 앨범 사진, 재생 시간을 띄워 주는 위젯 프로그램입니다. Spotify, YouTube Music, 멜론, Apple Music, TIDAL 등 어떤 플레이어로 듣든 상관없습니다. Windows가 알고 있는 "지금 재생 중" 정보(볼륨 키를 누르면 뜨는 그 정보)를 그대로 읽어 오기 때문입니다.

만든 사람: 김탄2

준비물

아래 네 가지가 갖춰져 있어야 합니다.

항목필요한 것
컴퓨터Windows 10(1809 이상) 또는 Windows 11
OBS브라우저 소스를 쓸 수 있는 OBS Studio (OBS Studio 32에서 확인)
음악 플레이어Windows의 "지금 재생 중"에 곡을 알려 주는 플레이어 (Spotify PC 앱 등)
설치 파일MusicNowPlayingWidget-v0.2.1.zip

따로 설치할 프로그램은 없습니다. 압축을 푼 폴더의 exe 하나만 실행하면 됩니다.

1단계: 프로그램 실행

  1. MusicNowPlayingWidget-v0.2.1.zip을 원하는 폴더에 압축을 풉니다.

  2. MusicNowPlayingWidget.exe를 더블클릭합니다.

  3. "Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 누릅니다. 개인이 만든 무료 프로그램이라 마이크로소프트 유료 인증서가 없어서 뜨는 경고입니다.

  4. 처음 실행하면 브라우저에 설정 페이지가 열립니다. 작업 표시줄 오른쪽 아래에 초록 음표 아이콘이 생기면 실행된 것입니다.

프로그램은 창 없이 트레이 아이콘으로만 돌아갑니다. 두 번 실행해도 하나만 켜집니다.

2단계: OBS에 위젯 넣기

  1. 설정 페이지의 OBS에 넣을 주소에서 원하는 모양 옆의 복사를 누릅니다. 트레이 아이콘 → 위젯 주소 복사를 써도 됩니다.

  2. OBS에서 소스 추가(+) → 브라우저를 고르고 이름을 정합니다.

  3. URL 칸에 복사한 주소를 붙여 넣습니다. 주소는 file:///C:/Users/.../MusicNowPlayingWidget/widget/widget.html?style=A처럼 생겼습니다(내 PC에 저장된 위젯 파일입니다).

  4. 너비와 높이를 아래 표대로 맞추고 확인을 누릅니다. 설정 페이지에서도 각 이름 아래에 크기가 적혀 있습니다.

모양주소 끝너비 × 높이생김새
카드형?style=A430 × 110앨범 사진, 제목, 가수, 진행 막대가 있는 카드. 뒤로 앨범 색이 은은하게 번집니다.
한 줄 알약형?style=B450 × 70둥근 알약 모양 한 줄. 작은 앨범 사진과 움직이는 음표 막대가 있습니다.
큰 글씨형?style=C560 × 140배경 상자 없이 큰 앨범 사진과 큰 글씨만 보입니다.

장면마다 다른 주소를 넣으면 장면별로 다른 모양을 쓸 수 있습니다. 위젯 배경은 투명합니다.

OBS와 이 프로그램 중 어느 쪽을 먼저 켜도 괜찮습니다. 위젯이 프로그램을 기다렸다가 알아서 연결합니다.

3단계: 곡 틀어 확인하기

  1. 음악 플레이어에서 곡을 재생합니다. 위젯에 제목, 가수, 앨범 사진이 나타납니다.

  2. 일시정지하면 1.5초 뒤 위젯이 사라지고, 다시 재생하면 나타납니다.

  3. 곡을 넘기면 이전 곡이 사라졌다가 새 곡이 나타납니다. 빠르게 연달아 넘기면(0.8초 안에 다시 넘기면) 기다리지 않고 바로바로 바뀝니다.

위젯이 안 나오면 맨 뒤의 문제 해결을 확인해 주세요.

설정 페이지

트레이 아이콘 → 설정 열기를 누르거나, 브라우저에서 http://localhost:8976/settings를 엽니다. 바꾼 뒤 저장을 누르면 OBS 위젯에 바로 반영되고, OBS를 새로고침할 필요는 없습니다. 오른쪽 미리보기에서 저장 전에 모습을 볼 수 있습니다.

항목설명
모양주소에 ?style=를 붙이지 않은 위젯의 기본 모양
색글자색, 배경색, 포인트색(진행 막대, 음표 막대)

Windows 시작 시 자동 실행켜면 Windows에 로그인할 때 프로그램이 저절로 켜집니다. 처음에는 꺼져 있습니다. 프로그램 폴더를 옮기면 자동 실행이 안 될 수 있으니, 옮긴 뒤에는 새 위치에서 한 번 직접 실행해 주세요.
언어자동(Windows 언어) / 한국어 / English / 日本語. 설정 페이지와 트레이 메뉴의 글자가 바뀝니다.

브라우저가 처음에 꺼져 있는 이유

Chrome, Edge, Whale 같은 브라우저는 유튜브 영상이나 인터넷 방송 소리도 "재생 중"으로 잡힙니다. 그래서 방송 중에 영상 제목이 뜨지 않도록 브라우저는 처음에 꺼져 있습니다.

Windows는 "어느 브라우저에서 재생 중인지"만 알려 주고, 어느 사이트인지는 알려 주지 않습니다. 그래서 Chrome을 켜면 YouTube Music뿐 아니라 Chrome에서 트는 방송과 영상도 모두 위젯에 나옵니다. YouTube Music만 보이게 하려면 다음 항목대로 설정해 주세요.

YouTube Music만 표시하기 (방송·영상 소리는 빼고)

YouTube Music을 Chrome 앱으로 설치하면 Windows가 일반 Chrome과 따로 알려 줍니다. 그러면 YouTube Music만 켜고 Chrome은 꺼 둘 수 있습니다.

  1. Chrome에서 music.youtube.com을 엽니다.

  2. 주소창 오른쪽 끝의 설치 아이콘(모니터에 아래 화살표 모양)을 누르고 설치를 누릅니다. 아이콘이 안 보이면 오른쪽 위 점 세 개 모양 메뉴 → 전송, 저장, 공유 → 페이지를 앱으로 설치를 누릅니다.

  3. 새로 열린 YouTube Music 창에서 곡을 재생합니다. 다음부터는 바탕화면이나 시작 메뉴의 YouTube Music 아이콘으로 열면 됩니다.

  4. 설정 페이지의 표시할 앱에 YouTube Music (Chrome 앱)이 생기면 체크를 켜고, Chrome은 끈 채로 저장합니다.

이렇게 하면 YouTube Music 창에서 트는 곡은 커버곡처럼 앨범 정보가 없는 곡도 위젯에 나오고, 일반 Chrome 탭의 방송과 영상은 나오지 않습니다.

트레이 메뉴

작업 표시줄 오른쪽 아래의 초록 음표 아이콘을 오른쪽 클릭하면 나오는 메뉴입니다. 아이콘을 더블클릭하면 바로 설정 페이지가 열립니다.

메뉴하는 일
설정 열기브라우저에 설정 페이지를 엽니다.
위젯 주소 복사OBS에 넣을 위젯 주소(기본 모양)를 복사합니다.
다시 시작프로그램을 껐다가 다시 켭니다. OBS 위젯은 알아서 다시 연결됩니다.
종료프로그램을 끕니다. 위젯은 곡 정보가 없어 보이지 않게 됩니다.

새 버전으로 바꿔서 실행하면 OBS 위젯도 스스로 한 번 새로고침해서 새 버전으로 바뀝니다.

문제 해결

증상원인해결
위젯이 안 보임곡이 일시정지 상태이거나, 그 플레이어가 꺼져 있음곡이 실제로 재생 중인지, 설정 → 표시할 앱에서 그 플레이어가 켜져 있는지 확인
Chrome의 방송이나 영상 제목이 뜸표시할 앱에서 Chrome이 켜져 있음Chrome 체크를 끄고 저장. YouTube Music은 앞의 방법대로 Chrome 앱으로 설치
"8976번 포트를 다른 프로그램이 쓰고 있어서 시작할 수 없어요" 창이 뜸다른 프로그램이 같은 번호를 씀%APPDATA%\MusicNowPlayingWidget\settings.json을 메모장으로 열어 "port": 8976의 숫자를 바꾸고(예: 8977) 프로그램을 다시 켬. OBS에 넣은 주소는 그대로 둬도 됨
설정 페이지가 안 열림주소를 127.0.0.1로 씀localhost로 열기. Windows가 관리자 권한 없이는 localhost만 허락함
앨범 사진이 안 나옴플레이어가 사진을 보내지 않음, 또는 앨범 사진 보이기가 꺼짐설정에서 앨범 사진이 켜져 있는지 확인. 사진은 곡이 바뀐 뒤 몇 초 늦게 올 수도 있음
뭔가 이상하게 동작함-트레이 아이콘 → 다시 시작. 그래도 안 되면 OBS의 브라우저 소스 속성에서 "현재 페이지의 캐시 새로 고침"
