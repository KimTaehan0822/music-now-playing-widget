# OBS 再生中ウィジェット

[English](README.md) | [한국어](README.ko.md) | **日本語**

配信画面に、いま聴いている曲のタイトル・アーティスト・アルバムアートを表示するウィジェットです。
Spotify、YouTube Music、Melon、Apple Music、TIDALなど、どのプレイヤーでも使えます。
Windowsが把握している「再生中」の情報（音量キーを押すと出てくるあの情報）をそのまま読み取るからです。

- Windows 10（1809以降）/ Windows 11 専用
- インストール不要：exeを1つ実行するだけ
- 3つのデザイン：カード、ピル（1行）、大きな文字
- 色・表示項目・言語（한국어/English/日本語）を設定ページで変更できます

## 使い方

1. `ObsNowPlaying-v0.1.0.zip` をダウンロードし、好きなフォルダーに展開します。
2. `ObsNowPlaying.exe` をダブルクリックします。
   - **青い「WindowsによってPCが保護されました」画面が出たら**：`詳細情報` → `実行` を押してください。
     個人が作った無料ソフトで、Microsoftの有料証明書がないため表示される警告です。
   - 初回起動時はブラウザで設定ページが開きます。以降はタスクバー右下の緑の音符アイコンから開けます。
3. OBSで `ソースを追加（+）` → `ブラウザ` を選び、URL欄に次のアドレスを入れます。

   ```
   http://localhost:8976/widget
   ```

   | デザイン | URL | 推奨サイズ（幅 × 高さ） |
   |---|---|---|
   | 設定で選んだ標準デザイン | `http://localhost:8976/widget` | デザインによる |
   | カード | `http://localhost:8976/widget?style=A` | 430 × 110 |
   | ピル（1行） | `http://localhost:8976/widget?style=B` | 450 × 70 |
   | 大きな文字 | `http://localhost:8976/widget?style=C` | 560 × 140 |

   シーンごとに別のURLを入れれば、シーンごとに違うデザインを使えます。背景は透明です。
4. 音楽を再生するとウィジェットが表示されます。一時停止すると少し後に消え、再生すると再び表示されます。

> **このアプリはOBSより先に起動してください。** OBSを先に起動した場合、ウィジェットは空白のままになります。
> その場合はブラウザソースをダブルクリックし、`現在のページのキャッシュを更新`を押してください。
> OBSを開いたままこのアプリだけを再起動するのは問題ありません。ウィジェットが自動で再接続します。

## 設定ページ

トレイアイコン → `設定を開く`（またはブラウザで `http://localhost:8976/settings`）

- **デザイン**：URLに `?style=` を付けないウィジェットの標準デザイン
- **色**：文字色、背景色、アクセント色（再生バーなど）
- **アルバムアート / 再生バー** の表示・非表示
- **表示するアプリ**：一度でも再生したアプリが一覧に出ます。チェックを外すと、そのアプリの曲はウィジェットに出ません。
- **言語**：自動（Windowsの言語）/ 한국어 / English / 日本語

保存するとOBSのウィジェットにすぐ反映されます。再読み込みは不要です。

### ブラウザが最初オフになっている理由

Chrome・Edge・Whaleなどのブラウザは、YouTube動画の音も「再生中」として扱われます。配信中に動画のタイトルが出ないよう、最初はオフにしてあります。
**YouTube Musicをブラウザで聴く場合は**、設定 → 表示するアプリでそのブラウザをオンにしてください。

同じブラウザ内の「YouTube Musicのタブ」と「通常のYouTubeのタブ」は区別できません（Windowsがブラウザ単位でしか教えてくれないためです）。

## プレイヤー別の確認状況

| プレイヤー | 状況 |
|---|---|
| Spotify（デスクトップアプリ） | ✅ 確認済み |
| YouTube Music（ブラウザ） | ⏳ 未確認 |
| Melon（デスクトップアプリ） | ⏳ 未確認 |
| Apple Music（Windowsアプリ） | ⏳ 未確認 |
| TIDAL（デスクトップアプリ） | ⏳ 未確認 |

Windowsの「再生中」情報に曲を出すプレイヤーなら動作します。音量キーを押したときに曲名が出れば、ほぼ確実に使えます。
試した結果を教えていただければ表を更新します。

## トラブルシューティング

- **「ポート8976は他のプログラムが使用中」と出る**：
  `%APPDATA%\ObsNowPlaying\settings.json` をメモ帳で開き、`"port": 8976` の数字を変えて（例：8977）、OBSのURLの数字も同じにします。
- **ウィジェットが表示されない**：音楽が本当に再生中か、設定 → 表示するアプリでそのプレイヤーがオンになっているか確認してください。
- **終了**：トレイアイコン → `終了`
