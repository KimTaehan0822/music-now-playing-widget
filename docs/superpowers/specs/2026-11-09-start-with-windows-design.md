# Windows 시작 시 자동 실행 — 짧은 설계

## 왜
지금은 컴퓨터를 켤 때마다 프로그램을 직접 실행해야 한다. 방송 전에 잊으면 위젯이 비어 있다. 내려받은 다른 사람도 체크 하나로 자동 실행을 켜고 끌 수 있어야 한다.

## 사용자가 정한 것
- 설정 페이지에 **"Windows 시작 시 자동 실행"** 체크를 추가한다.
- 기본값은 **꺼짐**. 사용자가 직접 체크해야 켜진다.
- 체크 아래에 **폴더를 옮기면 자동 실행이 안 될 수 있다**는 안내를 보여 준다.
- 방법은 **Windows 자동 실행 목록(레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`)** 에 등록하는 것(방법 1).

## 목표가 아닌 것
- 실행 지연, 관리자 권한, 모든 사용자 계정에 등록.
- 설치 프로그램 만들기.

## 방법 비교
1. **레지스트리 Run에 등록 (선택됨)** — 관리자 권한이 필요 없고 내 계정에만 적용된다. 작업 관리자 "시작 앱"에 보여 거기서도 끌 수 있다. 코드가 가장 짧다.
2. 시작 폴더 바로가기 — 결과는 비슷하지만 바로가기(.lnk)를 만드는 코드가 따로 필요하고, 실수로 지우기 쉽다.
3. 작업 스케줄러 — 세밀한 조절이 되지만 복잡하고 권한 문제가 생길 수 있어 과하다.

## 동작
- **켜기**: 저장하면 Run에 값 이름 `MusicNowPlayingWidget`, 값 `"<지금 실행 중인 exe 전체 경로>"`(따옴표 포함)를 쓴다.
- **끄기**: 저장하면 그 값을 지운다(없으면 아무것도 안 함).
- **체크 표시의 기준은 레지스트리**다. 설정 페이지를 열면 Run에 값이 있는지로 체크 상태를 보여 준다. settings.json에는 저장하지 않는다(작업 관리자 등에서 바꾼 상태와 어긋나지 않게).
- **위치 맞추기**: 프로그램이 켜질 때 Run에 값이 있는데 경로가 지금 exe와 다르면 지금 경로로 고쳐 쓴다. 값이 없으면 새로 만들지 않는다.
- 자동 실행으로 켜질 때도 지금처럼 트레이 아이콘만 뜨고 창은 열리지 않는다(첫 실행만 설정 페이지를 연다 — 기존 동작 그대로).
- 레지스트리 쓰기가 실패하면 설정 저장 자체는 실패시키지 않고, 체크는 실제 상태(레지스트리)대로 다시 보여 준다.
