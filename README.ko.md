# Music Now Playing Widget (지금 재생 중 위젯)

[English](README.md) | **한국어** | [日本語](README.ja.md)

방송 화면에 지금 듣고 있는 곡의 제목, 가수, 앨범 사진을 띄워 주는 위젯이에요.
스포티파이, 유튜브 뮤직, 멜론, 애플 뮤직, 타이달 등 어떤 플레이어로 듣든 상관없어요.
Windows가 알고 있는 "지금 재생 중" 정보를 그대로 읽어 오기 때문이에요(볼륨 키를 누르면 뜨는 그 정보예요).

- Windows 10(1809 이상) / Windows 11 전용
- 설치할 것 없음: exe 하나만 실행하면 돼요
- 모양 3가지: 카드형, 한 줄 알약형, 큰 글씨형
- 색, 표시 항목, 언어(한국어/English/日本語)를 설정 페이지에서 바꿀 수 있어요
- zip 안에 PDF 사용설명서(한국어/English/日本語)가 들어 있어요. 원본은 [`docs/manual`](docs/manual) 폴더에 있어요

## 사용 방법

1. `MusicNowPlayingWidget-v0.3.2.zip`을 받아 원하는 폴더에 압축을 풀어요.
2. `MusicNowPlayingWidget.exe`를 더블클릭해요.
   - **"Windows의 PC 보호" 파란 창이 뜨면**: `추가 정보` → `실행`을 눌러요.
     개인이 만든 무료 프로그램이라 마이크로소프트 인증서가 없어서 뜨는 경고예요.
   - 처음 실행하면 브라우저에 설정 페이지가 열려요. 그 뒤로는 작업 표시줄 오른쪽 아래 초록 음표 아이콘에서 열 수 있어요.
3. 설정 페이지의 **OBS에 넣을 주소**에서 원하는 모양의 `복사`를 눌러요. 트레이 아이콘 → `위젯 주소 복사`를 써도 돼요.
   주소는 `file:///C:/Users/.../MusicNowPlayingWidget/widget/widget.html?style=A`처럼 생겼어요(내 PC에 저장된 위젯 파일이에요).
4. OBS에서 `소스 추가(+)` → `브라우저`를 고르고, URL 칸에 복사한 주소를 붙여 넣어요.

   | 모양 | 주소 끝 | 권장 너비 × 높이 |
   |---|---|---|
   | 카드형 | `?style=A` | 430 × 110 |
   | 한 줄 알약형 | `?style=B` | 450 × 70 |
   | 큰 글씨형 | `?style=C` | 560 × 140 |

   장면마다 다른 주소를 넣으면 장면별로 다른 모양을 쓸 수 있어요. 배경은 투명해요.
5. 음악을 재생하면 위젯이 나타나요. 일시정지하면 잠시 후 사라지고, 다시 재생하면 나타나요.

> OBS와 이 프로그램 중 어느 쪽을 먼저 켜도 괜찮아요. 위젯이 프로그램을 기다렸다가 알아서 연결해요.
> v0.1.0 초기판에서 `http://localhost:8976/widget` 주소를 넣었다면 위의 새 주소로 바꿔 주세요. 예전 주소는 프로그램이 먼저 켜져 있을 때만 동작해요.

## 설정 페이지

트레이 아이콘 → `설정 열기` (또는 브라우저에서 `http://localhost:8976/settings`)

- **모양**: 주소에 `?style=`을 붙이지 않은 위젯의 기본 모양
- **색**: 글자색, 배경색, 포인트색(진행 막대 등)
- **곡마다 자동 변경**: 켜면 곡이 바뀔 때마다 앨범 사진 색으로 부드럽게 바뀌어요. 글자는 항상 잘 보이는 색으로 정해져요. 앨범 사진이 없으면 위에서 고른 색을 쓰고, 큰 글씨형(C)은 포인트색만 바뀌어요.
- **앨범 사진 / 진행 막대 / 재생 시간(1:12 / 3:20)** 켜기·끄기
- **표시할 앱**: 한 번이라도 재생된 앱이 목록에 나타나요. 체크를 끄면 그 앱의 곡은 위젯에 나오지 않아요.
- **Windows 시작 시 자동 실행**: 켜면 Windows에 로그인할 때 프로그램이 저절로 켜져요(처음에는 꺼져 있어요). 프로그램 폴더를 옮겼다면 새 위치에서 한 번 직접 실행해 주세요.
- **언어**: 자동(Windows 언어) / 한국어 / English / 日本語

저장하면 OBS 위젯에 바로 반영돼요. 새로고침할 필요 없어요.

### 브라우저가 처음에 꺼져 있는 이유

크롬·엣지·웨일 같은 브라우저는 유튜브 영상 소리도 "재생 중"으로 잡혀요. 그래서 방송 중에 영상 제목이 뜨지 않도록 처음에는 꺼 두었어요.

Windows는 "어느 브라우저에서 재생 중인지"만 알려 주고, 어느 사이트인지는 알려 주지 않아요. 그래서 크롬을 켜면 유튜브 뮤직뿐 아니라 크롬에서 트는 방송·영상도 모두 위젯에 나와요.

### 유튜브 뮤직만 표시하기 (방송·영상 소리는 빼고)

유튜브 뮤직을 **크롬 앱으로 설치**하면 Windows가 일반 크롬과 따로 알려 줘요. 그러면 유튜브 뮤직만 켜고 크롬은 꺼 둘 수 있어요.

> **Windows 11에서만 돼요.** Windows 10은 유튜브 뮤직 앱 창에서 틀어도 일반 크롬과 같은 이름으로 알려 줘서 따로 켤 수 없어요.

1. 크롬에서 `music.youtube.com` 을 열어요.
2. 주소창 오른쪽 끝의 **설치 아이콘**(모니터에 아래 화살표 모양)을 누르고 **설치**를 눌러요.
   아이콘이 안 보이면 오른쪽 위 **⋮ 메뉴 → 전송, 저장, 공유 → 페이지를 앱으로 설치**를 눌러요.
3. 새로 열린 **YouTube Music 창**에서 곡을 틀어요. 다음부터는 바탕화면이나 시작 메뉴의 **YouTube Music 아이콘**으로 열면 돼요.
4. 설정 → 표시할 앱에 **YouTube Music (Chrome 앱)** 이 생기면 켜고, **Chrome** 은 끈 채로 **저장**해요.

이렇게 하면 유튜브 뮤직 창에서 트는 곡은 커버곡처럼 앨범 정보가 없는 곡도 위젯에 나오고, 일반 크롬 탭의 방송·영상은 나오지 않아요.

### 목록에 없는 프로그램 추가하기

표시할 앱 아래의 **실행 중인 프로그램 추가**를 누르면, 지금 창이 열려 있는 프로그램이 나와요. 음악을 트는 프로그램을 고르고 읽는 방식을 정한 뒤 **저장**해요.

- **Windows 곡 정보**: 곡을 틀기 전에 미리 켜기·끄기를 정해 둘 때 써요. 그 프로그램의 곡이 처음 잡히면 위 목록으로 합쳐져요.
- **창 제목**: Windows에 곡을 알려 주지 않는 프로그램용이에요. 창 제목에서 곡 이름을 읽어요. 순서는 **제목 - 아티스트** 또는 **아티스트 - 제목** 중에서 골라요.
  - 앨범 사진과 재생 시간은 나오지 않아요.
  - 창 제목에 곡 이름을 넣는 프로그램만 읽을 수 있어요.
  - 그 프로그램에서 소리가 나는 동안 재생 중으로 보고, 소리가 멈추고 3초쯤 지나면 위젯을 숨겨요.
  - Windows에서 재생 중인 곡이 있으면 그 곡을 먼저 보여 줘요.

## 플레이어별 확인 현황

| 플레이어 | 상태 |
|---|---|
| Spotify (PC 앱) | ✅ 확인됨 |
| YouTube Music (Chrome 앱으로 설치) | ✅ 확인됨 (Windows 11) |
| 멜론 (PC 앱) | ✅ 확인됨 |
| Apple Music (Windows 앱) | ⏳ 확인 중 |
| TIDAL (PC 앱) | ✅ 확인됨 |

Windows의 "지금 재생 중" 정보에 곡을 올리는 플레이어라면 동작해요. 볼륨 키를 눌렀을 때 곡 정보가 보이면 거의 확실히 돼요.
써 보신 결과를 알려 주시면 표를 고칠게요.

## 문제 해결

- **"8976번 포트를 다른 프로그램이 쓰고 있어요"**:
  `%APPDATA%\MusicNowPlayingWidget\settings.json`을 메모장으로 열어 `"port": 8976`의 숫자를 바꾸고(예: 8977) 프로그램을 다시 켜요. OBS에 넣은 파일 주소는 그대로 둬도 돼요.
- **주소는 `localhost`로 써 주세요.** `127.0.0.1`로 바꾸면 열리지 않아요(Windows가 관리자 권한 없이는 `localhost`만 허락해요).
- **위젯이 안 보여요**: 음악이 실제로 재생 중인지, 설정 → 표시할 앱에서 그 플레이어가 켜져 있는지 확인해요.
- **뭔가 이상할 때**: 트레이 아이콘 → `다시 시작`. OBS 위젯은 알아서 다시 연결돼요.
- **종료**: 트레이 아이콘 → `종료`
