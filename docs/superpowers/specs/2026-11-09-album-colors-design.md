# 앨범 색 자동 적용 — 짧은 설계

## 왜
곡마다 위젯 색이 앨범 사진 분위기를 따라가면 방송 화면이 곡과 어울린다. 인터넷 없이, 배포해도 바깥 사이트에 기대지 않는 방식으로.

## 사용자가 정한 것
- 설정 페이지는 지금처럼 사용자가 색을 고른다. 여기에 **'곡마다 자동 변경'** 체크를 추가한다. 기본값은 꺼짐.
- 켜면 곡이 바뀔 때 위젯 색이 앨범 사진에서 뽑은 색으로 바뀐다.
- 색은 한 번에 바뀌지 않고 **부드럽게 이어지듯** 바뀐다(약 1.2초).
- 색 계산은 **이 프로그램(C#)** 이 하고, 곡 정보와 함께 위젯에 보낸다(방법 1).
- 글자색은 어떤 앨범이 와도 **잘 읽히게** 알아서 정한다.

## 목표가 아닌 것
- 바깥 색 조합 사이트 연동, 추천색 목록 표시, 색을 골라 저장하는 기능.
- 사용자가 고른 색을 자동으로 덮어써 저장하는 것(자동 색은 저장되지 않고 화면에만 쓰인다).

## 방법 비교
1. **프로그램이 계산해 보냄 (선택됨)** — OBS(내 PC 파일로 연 위젯)와 설정 미리보기가 같은 색을 받는다. 계산을 자동 테스트로 확인할 수 있다.
2. 위젯이 사진을 받아 직접 계산 — 파일로 연 페이지가 다른 주소의 사진 픽셀을 읽는 것은 브라우저 보안 규칙에 막힐 수 있어 제외.

## 동작 (내가 정한 부분 포함)
- **색 뽑기**: 앨범 사진을 작게 줄여 비슷한 색끼리 묶고,
  - 배경색 = 가장 넓게 쓰인 색,
  - 강조색 = 배경과 다르면서 가장 선명한 색. 배경과 대비가 3:1보다 낮으면 밝기를 조절해 3:1 이상으로 만든다.
  - 글자색 = 배경 위에서 흰색과 아주 어두운 색 중 대비가 더 큰 쪽(WCAG 기준 항상 4.5:1 이상).
  - 사진 한 장당 한 번만 계산한다(사진이 바뀔 때만).
- **스타일별 적용**:
  - A(카드), B(알약): 배경·강조·글자색 모두 자동.
  - C(큰 글씨, 배경 상자 없음): 글자 뒤가 방송 화면이라 배경색을 쓰지 않는다. **강조색만** 자동, 글자색은 사용자가 고른 색 + 지금의 그림자 유지.
  - 진행 막대의 빈 부분도 글자색 기준으로 맞춰 밝은 배경에서도 보이게 한다.
- **자동 색을 안 쓰는 경우**: 체크 꺼짐, 앨범 사진 없음, 사진 해석 실패 → 사용자가 고른 색.
- **일시정지**: 지금처럼 마지막 화면 그대로 사라진다(색도 그대로).
- **설정 페이지**: 체크와 짧은 설명 한 줄(“앨범 사진이 없을 때는 위에서 고른 색을 써요” 취지). 미리보기 창도 체크 상태를 따른다. 3개 언어 문구.
- README 3개 언어에 한 줄씩 추가.
