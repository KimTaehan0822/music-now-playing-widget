# Music Now Playing Widget（再生中ウィジェット）

[English](README.md) | [한국어](README.ko.md) | **日本語**

配信画面に、いま聴いている曲のタイトル・アーティスト・アルバムアートを表示するウィジェットです。
Spotify、YouTube Music、Melon、Apple Music、TIDALなど、どのプレイヤーでも使えます。
Windowsが把握している「再生中」の情報（音量キーを押すと出てくるあの情報）をそのまま読み取るからです。

- Windows 10（1809以降）/ Windows 11 専用
- インストール不要：exeを1つ実行するだけ
- 3つのデザイン：カード、ピル（1行）、大きな文字
- 色・表示項目・言語（한국어/English/日本語）を設定ページで変更できます
- zipにはPDFの取扱説明書（한국어/English/日本語）が入っています。元ファイルは [`docs/manual`](docs/manual) フォルダーにあります

## 使い方

1. `MusicNowPlayingWidget-v0.1.0.zip` をダウンロードし、好きなフォルダーに展開します。
2. `MusicNowPlayingWidget.exe` をダブルクリックします。
   - **青い「WindowsによってPCが保護されました」画面が出たら**：`詳細情報` → `実行` を押してください。
     個人が作った無料ソフトで、Microsoftの有料証明書がないため表示される警告です。
   - 初回起動時はブラウザで設定ページが開きます。以降はタスクバー右下の緑の音符アイコンから開けます。
3. 設定ページの **OBSに入れるURL** で、使いたいデザインの `コピー` を押します。トレイアイコン → `ウィジェットのURLをコピー` でも構いません。
   アドレスは `file:///C:/Users/.../MusicNowPlayingWidget/widget/widget.html?style=A` のような形です（PCに保存されたウィジェットファイルです）。
4. OBSで `ソースを追加（+）` → `ブラウザ` を選び、URL欄にコピーしたアドレスを貼り付けます。

   | デザイン | アドレスの末尾 | 推奨サイズ（幅 × 高さ） |
   |---|---|---|
   | カード | `?style=A` | 430 × 110 |
   | ピル（1行） | `?style=B` | 450 × 70 |
   | 大きな文字 | `?style=C` | 560 × 140 |

   シーンごとに別のアドレスを入れれば、シーンごとに違うデザインを使えます。背景は透明です。
5. 音楽を再生するとウィジェットが表示されます。一時停止すると少し後に消え、再生すると再び表示されます。

> OBSとこのアプリはどちらを先に起動しても大丈夫です。ウィジェットがアプリを待って自動で接続します。
> 最初のv0.1.0で `http://localhost:8976/widget` を入れていた場合は、上の新しいアドレスに替えてください。古いアドレスはアプリが先に起動しているときしか動きません。

## 設定ページ

トレイアイコン → `設定を開く`（またはブラウザで `http://localhost:8976/settings`）

- **デザイン**：URLに `?style=` を付けないウィジェットの標準デザイン
- **色**：文字色、背景色、アクセント色（再生バーなど）
- **曲ごとに自動で色を変える**：オンにすると、曲が変わるたびにアルバムアートの色へなめらかに変わります。文字は常に読みやすい色になります。アルバムアートがない曲は上で選んだ色を使い、大きな文字（C）スタイルはアクセント色だけが変わります。
- **アルバムアート / 再生バー / 再生時間（1:12 / 3:20）** の表示・非表示
- **表示するアプリ**：一度でも再生したアプリが一覧に出ます。チェックを外すと、そのアプリの曲はウィジェットに出ません。
- **Windows の起動時に自動で実行**：オンにすると、Windows にサインインしたときにプログラムが自動で起動します（最初はオフ）。プログラムのフォルダーを移動したら、新しい場所から一度手動で起動してください。
- **言語**：自動（Windowsの言語）/ 한국어 / English / 日本語

保存するとOBSのウィジェットにすぐ反映されます。再読み込みは不要です。

### ブラウザが最初オフになっている理由

Chrome・Edge・Whaleなどのブラウザは、YouTube動画の音も「再生中」として扱われます。配信中に動画のタイトルが出ないよう、最初はオフにしてあります。

Windowsは「どのブラウザで再生中か」だけを伝え、どのサイトかは伝えません。そのためChromeをオンにすると、YouTube MusicだけでなくChromeで流す配信や動画もすべてウィジェットに出ます。

### YouTube Musicだけを表示する（動画・配信の音は除く）

YouTube Musicを**Chromeアプリとしてインストール**すると、Windowsは通常のChromeとは別に伝えます。これでYouTube Musicだけをオンにし、Chromeはオフにしておけます。

1. Chromeで `music.youtube.com` を開きます。
2. アドレスバー右端の**インストールアイコン**（モニターに下向き矢印）を押し、**インストール**を押します。
   見当たらない場合は、右上の **⋮ メニュー → キャスト、保存、共有 → ページをアプリとしてインストール** を押します。
3. 新しく開いた **YouTube Music のウィンドウ**で曲を再生します。次回からはデスクトップやスタートメニューの **YouTube Music アイコン**から開いてください。
4. 設定 → 表示するアプリに **YouTube Music (Chrome アプリ)** が出たらオンにし、**Chrome** はオフのまま**保存**します。

これでYouTube Musicのウィンドウで流す曲は、カバー曲のようにアルバム情報がない曲も表示され、通常のChromeタブの配信や動画は表示されません。

## プレイヤー別の確認状況

| プレイヤー | 状況 |
|---|---|
| Spotify（デスクトップアプリ） | ✅ 確認済み |
| YouTube Music（Chromeアプリとしてインストール） | ✅ 確認済み |
| Melon（デスクトップアプリ） | ⏳ 未確認 |
| Apple Music（Windowsアプリ） | ⏳ 未確認 |
| TIDAL（デスクトップアプリ） | ⏳ 未確認 |

Windowsの「再生中」情報に曲を出すプレイヤーなら動作します。音量キーを押したときに曲名が出れば、ほぼ確実に使えます。
試した結果を教えていただければ表を更新します。

## トラブルシューティング

- **「ポート8976は他のプログラムが使用中」と出る**：
  `%APPDATA%\MusicNowPlayingWidget\settings.json` をメモ帳で開き、`"port": 8976` の数字を変えて（例：8977）、アプリを再起動します。OBSに入れたファイルのアドレスはそのままで構いません。
- **アドレスは `localhost` のまま使ってください。** `127.0.0.1` に変えると開けません（管理者権限なしでは、Windowsは `localhost` しか許可しないためです）。
- **ウィジェットが表示されない**：音楽が本当に再生中か、設定 → 表示するアプリでそのプレイヤーがオンになっているか確認してください。
- **調子がおかしいとき**：トレイアイコン → `再起動`。OBSのウィジェットは自動で再接続します。
- **終了**：トレイアイコン → `終了`
